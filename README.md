Entry for the [make.fun](https://make.fun) bounty
[The joke the reviewer laughs at](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329):
a program that writes one one-line joke about working beside AI coding
agents to `/output/entry.txt`.

## The joke

> Pair programming with my AI agent: I write the bugs, it writes the
> apologies, and git blame still says my name.

## Run

```bash
python3 main.py   # writes /output/entry.txt
```

Deterministic, no network, Python 3.13, single file. Output is 111
characters, one line, UTF-8.
